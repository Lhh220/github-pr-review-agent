# 独立复验样本

本目录新增 4 个手工编写的小样本，覆盖除零、空切片越界及对应防护正常代码。它们独立于此前用于调整提示词的 9 个主样本，不并入主集成绩。

脚本只验证工具、校验、评分链路；本轮尚未使用 live 输出调优这些样本。它们仍然简单，后续应补充来自真实 PR、经人工复核的独立样本。一旦根据这里的模型错误修改提示词，该集合就不再是未参与调优的保留集，应另留新样本。

```powershell
go run ./cmd/eval -cases eval/holdout -live -runs 3 -timeout 30m
```

不指定 `-report` 时自动生成带时间戳的新文件；指定一个已存在的报告路径会拒绝覆盖。
